关于我们

上海第二工业大学程序设计竞赛协会是计算机与信息工程学院下的以算法和编程竞赛为核心的学术科技类社团。协会主要负责组织和指导我校学生参加国际大学生程序设计竞赛（ICPC）、中国大学生程序设计竞赛（CCPC）、团体程序设计天梯赛（GPLT）和蓝桥杯软件设计大赛。

我们拥有独立备赛使用的算法训练室28号楼705，室内配备有稳定的千兆网络、专用练习电脑。通过"以赛促学，学赛共进"的模式，发掘和培养优秀的软件设计后备人才。

在这里，每一位零基础或已具备一定底子的算法爱好者，都能通过层层磨练，完成从代码小白到金牌选手的华丽蜕变。

算法选手成长路线图

我们针对零基础同学量身定制的四年阶梯式算法学习成长路线，为你铺平算法竞赛的升级之路。

第一阶段：语法基础与电子扫盲

学习C/C++基础编程语法，熟悉输入输出、循环控制语句、一维/二维数组的应用。学习如何在本地配置VS Code和g++编译器环境，熟练使用基础终端指令。

C++ Primer Plus 洛谷 [入门1] 题单 VS Code 环境配置

第二阶段：基础算法与 STL 容器

掌握排序与检索（二分查找）、高精度计算、前缀和与差分、双指针法和贪心策略。学习并熟练运用C++ Standard Template Library (STL)，如 vector, map, set, queue, stack 等数据结构。

洛谷 [算法1-1] Codeforces Div.3/Div.4 AtCoder ABC A-C 题

第三阶段：数据结构与中级算法

深入学习基础图论（DFS/BFS深度与广度优先搜索、Dijkstra单源最短路径、Kruskal最小生成树）、基础动态规划（背包问题、线性DP）及常用基础数学算法（素数筛、最大公约数、快速幂）。

《算法竞赛进阶指南》 AtCoder ABC D-E 题 Codeforces Div.2 B-C

第四阶段：高级算法与真题实战

学习高级数据结构（线段树、树状数组、并查集优化、强连通分量）、高级DP（区间DP、状压DP）。研究ICPC/CCPC历年亚洲区域赛真题，磨砺3人组队配合默契、战术分工及应对高压的解题能力。

ICPC 区域赛真题 CCPC 组队模拟赛 模板源程序集锦 (Template)
